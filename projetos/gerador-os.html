Gerador de OS

Painel que busca as tarefas de um cliente na API da Auvo e monta a ordem de serviço em PDF com o cabeçalho da empresa. O questionário entra ou não conforme o grupo do cliente final.

Meu papel
Desenvolvimento e integração ao portal
Para quem
Empresa de manutenção de elevadores
Stack
React, API Auvo, react-pdf, n8n
Experimente: filtre as tarefas, abra uma OS e baixe o PDF. Clientes do grupo "com questionário" recebem a seção extra. Dados fictícios
    Escolha uma tarefa para ver a OS.

    O problema

    O cliente precisava entregar ordens de serviço no mesmo formato do relatório de tarefas da Auvo, mas com o próprio cabeçalho (logo, CNPJ e endereço). Parte dos clientes finais exige o questionário preenchido pelo técnico e parte não, e isso era decidido à mão a cada envio.

    O que construí

    • Login com a chave e o token da API da Auvo do próprio cliente, numa sessão temporária. O acesso à API é somente leitura.
    • Filtros por período, status, cliente, técnico, código da tarefa e grupo do cliente, com a tabela mostrando o grupo de cada tarefa.
    • OS em PDF com cabeçalho, dados do cliente, técnico, check-in e check-out, questionário em grade com fotos e equipamentos, e numeração de páginas.
    • Regra do questionário pelo grupo do cliente. Se o cliente não está em nenhum grupo, a OS sai sem questionário e o caso fica registrado para revisão.
    • Envio por e-mail por um fluxo próprio no n8n, com destinatários extras configuráveis e registro dos envios.

    Depois desse, trabalhei em outros geradores no mesmo formato: relatório de chamados com exportação para Excel, PMOC com ficha por equipamento e histórico de atendimentos por equipamento.

    Stack

    React, TypeScript, API REST da Auvo v2, @react-pdf/renderer, n8n para o envio de e-mails, integrado ao portal interno da Auvo.
