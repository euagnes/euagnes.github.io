Etiquetas com QR Code

Geradores de etiquetas para colar nos equipamentos dos clientes. Quem escaneia o QR Code abre direto uma solicitação de atendimento para aquele equipamento, sem precisar saber o número dele.

O problema

A Auvo já oferecia quatro formatos de etiqueta, mas um cliente com centenas de equipamentos precisava de uma etiqueta quadrada de 5 × 5 cm com a própria marca. Outro queria um modelo vertical com telefone, e-mail e horário de plantão, para o cliente final saber a quem recorrer.

O que construí

  • Documento de descoberta com o cliente antes de codar: tamanho, ordem das informações e para onde o QR Code deve levar.
  • Etiqueta quadrada de 50 × 50 mm com logo, QR Code, nome e identificador do equipamento, distribuída numa folha A4 com numeração de páginas. Depois ganhou layout horizontal e seletor de tamanho.
  • Etiqueta vertical com logo, contatos, QR Code, nome do cliente e horário de atendimento, em dois tamanhos (6 ou 12 por folha), logo enviado pelo usuário e opção de esconder qualquer linha.
  • Painel com busca por nome, identificador, categoria e status, seleção múltipla e "selecionar todos os filtrados".

O QR Code leva a uma página de abertura de chamado já preenchida com o equipamento, então o cliente final só descreve o problema.

Stack

React, Vite, TypeScript, API REST da Auvo por um proxy que só permite leitura, testes escritos antes do código com Vitest.
